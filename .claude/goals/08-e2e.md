## Scenarios
1. `/start` → `/menu` → tap **Workflows** → select fixture → confirm "active workflow set"
2. tap **Chat with Agent** → send `"Ciao"` → assert reply within 10 s
3. tap **🎙️ Voice Call** → assert WebApp button with valid signed URL appears
4. send a voice note → assert text + voice reply within 15 s (Whisper STT in CI requires `GROQ_API_KEY` secret)
5. **Memory**: `/remember "test fact"` → `/memory search test` → assert fact in result
6. **Scheduled Tasks**: schedule message for `now + 60 s` → wait 70 s → assert message delivered

## Telegram test server
Use [tdlib/telegram-bot-api](https://github.com/tdlib/telegram-bot-api) in local mode, OR a stub that speaks the Bot API HTTP surface for tests. Real Telegram Bot API for CI runs is rate-limited; the local server is faster.
